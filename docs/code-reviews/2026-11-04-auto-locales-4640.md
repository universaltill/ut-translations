Status: **reviewed, safe to merge** (Tester 2026-11-04, independent Reviewer
2026-11-04 on a different model from the Dev's). Binding: ADR-0160 §4 (review
gate stays absolute) and §5 (who can publish, least privilege).

## Reviewer: what was checked
Workflow injection (`inputs.locale` reaches shell only through `env:` and
`"$LOCALE"`; artifact names and `--locale` after `validate` use the
regex-validated `needs.validate.outputs.tag`; `${{ }}` in no `run:` body;
the concurrency group carries the raw input as a plain string, which is
not evaluated); secret exposure (`validate` has no `secrets.`, no
`environment`; even a hostile `vars.WEBLATE_URL` can only make `validate`
pass or fail — its two outputs come from the regex-checked code and the
CODEOWNED overrides, never from the response); environment routing
(`environment:` is a literal on both publish jobs; `human == 'true'` and
`== 'false'` are exclusive, an empty output runs neither; `build` and
`verify` re-validate the code themselves); tag collisions (`pt_BR` vs
`pt_br` refused for the whole list, overrides checked the same way; the
tag charset `[a-z]{2,3}(-[a-z0-9]{2,8})?` cannot traverse paths); the
Weblate-controlled display name (reaches only `manifest.name`/`description`
after `clean_name`: letters, marks, digits, space, `()-'.,`, 64 chars; not
`review.md`, not shell, not `$GITHUB_OUTPUT`); fail-closed when Weblate is
down (404/5xx/redirect/empty/non-JSON all raise; `fetch_languages` catches
every client exception); the review gate (`review_verdict`, `Accounts`,
legal-needs-human, author != approver, model separation untouched;
`DerivedLanguages.test_review_gate_is_the_same_for_a_derived_language`
proves the same verdicts for a derived language); byte-identity of the seven
existing specs (`frozen_bundle_specs.json`); CODEOWNERS; test false-passes.

## Findings

| # | Severity | Finding | Outcome |
|---|---|---|---|
| 1 | **Medium** | A regional/script variant of a human spot-check language (`de_DE`, `de_AT`, `en_GB`, `tr_CY`) had no override, so `human=false` and it published through `bundle-publish` with no required reviewer. Weblate's project allows `new_lang: add`, so adding `de_DE` there was enough to ship German strings without the §4 spot-check. | **Fixed.** `locales.human_spot_check(cfg, code)`: own override first, else the base language's (`de_AT` -> `de`), else false; only `human_spot_check` is inherited (never `source`/`min_coverage`); an explicit CODEOWNED override still wins. Used by `derive_spec` and the `--check` CLI. Tests: `Spec.test_a_variant_of_a_human_language_is_human`, CLI cases `de_AT`/`en_GB`; red confirmed on the pre-fix code (`human=false`), green after. README and the bundles.json note say so. |
| 2 | Low | `test_artifact_names_use_the_validated_tag_only` was a tautology: `(bundle-\S+)` captured only `bundle-${{`, so `"needs" in n` was never true and the assertion compared `n` with itself. | **Fixed.** Captures the whole name; every artifact name must equal `bundle-${{ needs.validate.outputs.tag }}` exactly; `github.event.inputs` (the raw input under another name) is refused anywhere in the file. Mutant (artifact name = `github.event.inputs.locale`) killed. |
| 3 | Low | `tests/test_workflow.py` and `tests/test_bundle.py` (the guards that pin the workflow's security shape and the review gate) were not CODEOWNED while `test_locales.py` was. | **Fixed.** Both added to CODEOWNERS and to the CODEOWNERS test. |
| 4 | Info | `fetch_languages_public` reads the response with no size cap; a hostile `WEBLATE_URL` repository variable could only stall the 5-minute `validate` job. | Accepted: the job times out, outputs are not influenced. |
| 5 | Info | The bash `[a-z]` range in the first `validate` step depends on the runner locale; the real gate is Python's `CODE_RE` in the same job, and `build`/`verify` re-check. | Accepted. |

## Residual risks (not blockers)
- The authenticated path `build` uses (`GET /api/projects/<p>/languages/`
  with `WEBLATE_BUNDLE_TOKEN`) has not run in CI yet; the workflow is
  dispatch-on-main only. First dry run after merge (publish unticked) proves
  it; a 403 fails closed.
- `vars.WEBLATE_URL` must exist as a repository variable for `validate`;
  otherwise the hard-coded public URL is used (same host).
- Whether the till treats `de-de` as a fallback for `de` was not traced; the
  human gate now covers it either way.
