## Live provisioning against translate.universaltill.com (same day)
The first live run found three gaps between the fake and the real Weblate
2026.10.1.1 API. Each was fixed test-first by making the fake match the real
behaviour (red), then fixing the client (green):
- GET `.../addons/` returns 405 (POST only). The add-ons are now read from the
  component's `addons` URLs.
- A `weblate://` linked component refuses its own VCS options (`branch`,
  `push`, …). They are now set only on the owner component.
- A linked component reads back resolved (`repo` = the owner's clone URL,
  plus `linked_component`). It is now compared by the link, so a re-run
  makes 0 writes.
Result: project `universal-till` with dedicated reviewers, 13 components,
3,469 source strings with explanations, flags and the `legal` label.
